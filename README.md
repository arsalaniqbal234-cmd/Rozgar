# Rozgar — Job Listings Platform

A full-stack web app that scrapes remote job listings and displays them in a clean, searchable interface.

## Tech Stack
- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL
- **Scraper:** Python (requests)

## Features
- Scrapes live job data from RemoteOK API
- REST API with GET/POST endpoints for jobs
- Searchable job listing frontend
- Clean, modern UI
